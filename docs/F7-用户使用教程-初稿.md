# F7 用户使用教程（初稿）

- 适用：dsh-pet 桌面宠物 + Agent 工作模式（dsh-pet-task-ctl 桥接）
- 说明：以下"小鱼"指你桌面上那只宠物；所有命令都在**宠物的聊天窗口**里输入（和平时跟它说话是同一个输入框）。

---

## 1. 一分钟上手

打开宠物聊天窗，直接输入：

```
/task 在工作区创建一个文件 hello.txt，内容写：你好呀
```

宠物会立刻回你"已收到任务 #xxx"，然后：
1. 它的**状态动画会亮起来**（思考中→干活中）；
2. 干完后它会**汇报关键结果和文件路径**；
3. 想知道进度，随时问：`/task status`

就这么简单——**像使唤一个小助手一样打字就行，不用打开任何别的窗口**。

## 2. 任务命令

| 命令 | 作用 | 示例 |
|---|---|---|
| `/task <描述>` | 交一个任务给 Agent 真实执行 | `/task 在工作记录文件夹里建一个本周记录` |
| `/task status` | 看最近任务的状态和结果 | `/task status` |
| `/task list` | 列出最近几个任务 | `/task list` |
| `/task cancel` | 取消正在做的任务 | `/task cancel` |

**注意**：
- 一次只能交一个任务；上一个没做完时再交，宠物会提醒你等一下或先取消。
- 任务是**真实执行**的：它会真的创建/修改你工作区里的文件。
- 如果任务里涉及敏感操作，DSH 弹出**审批**时，宠物会显示"等待批准"，需要你去 DSH 窗口点一下——宠物不会替你点头。
- 任务做完会接着上一次的上下文继续（同一个会话），所以可以连续交代："再往那个文件里补两条"这种话它是听得懂的。

## 3. 记忆命令（让它更懂你）

| 命令 | 作用 | 示例 |
|---|---|---|
| `/称呼 小明` | 告诉它怎么叫你 | `/称呼 老板` |
| `/memory add <内容>` | 记住一条你的偏好 | `/memory add 周报只写实际完成的工作` |
| `/memory list` | 查看它记住了什么 | `/memory list` |
| `/memory del <序号>` | 删掉某条记忆 | `/memory del 2` |
| `/memory clear` | 清空偏好（称呼保留） | `/memory clear` |

**它记得的东西有两个用处**：聊天时会用（叫你的称呼、记得你的喜好）；**干活时也会用**——你让它写周报，它会自动带上"周报只写实际完成的工作"这条规矩，不用每次重复。

记忆保存在本地文件里，宠物程序重启也不会忘。

## 4. 命令速查

```
/bridge                —— 查看全部命令帮助
/task <描述>           —— 交任务
/task status           —— 任务进度
/task list             —— 任务列表
/task cancel           —— 取消任务
/memory list           —— 看记忆
/memory add <内容>     —— 记一条
/memory del <序号>      —— 删一条
/memory clear          —— 清空偏好
/称呼 <名字>            —— 设置称呼
```

**不用命令、直接说话也可以**：不以 `/` 开头的任何话，都和以前一样是普通聊天，宠物会按它的性子陪你说。

## 5. 三个实战例子（对应本次验收场景）

**例 1：建个文件**
> 你：`/task 在工作区创建 hello.txt，内容为：你好，我是你的 AI 小鱼。`
> 小鱼：已收到任务 #…（几秒后）主人，都办好了～ 文件在工作区根目录，34 字节，我回读校验过了。

**例 2：建工作记录**
> 你：`/task 在工作区创建「工作记录」文件夹，并在里面创建本周（11月2日至8日）的工作记录 worklog-week.txt，每天至少写一件完成的事`
> 小鱼：（干完后）工作记录文件夹建好了，7 天逐日记录完整，路径给你……

**例 3：连续交代 + 生成周报**
> 你：`/task 往刚才的 worklog-week.txt 里补两件事：完成了回归测试、完成了周报功能验证；然后基于它生成周报 weekly-report.md`
> 小鱼：两件事都办妥啦，周报在「工作记录」文件夹里，有按日表格和本周小结……

（因为会话是连续的，"刚才的文件"这种指代它也听得懂。）

## 6. 常见问题

**Q：任务卡住了/不想要了怎么办？**
`/task cancel` 立刻取消。排队的任务会直接撤回，执行中的会中断，不会留半成品。

**Q：宠物说"等待批准"？**
你的任务触发了 DSH 的安全审批（比如要动敏感路径）。去 DSH 主界面批准或拒绝——这是保护你的设计，宠物不代答。

**Q：重启电脑后它还记得我吗？**
记得。称呼、偏好、任务用的会话都会从本地文件恢复。只有"任务历史列表"是本次运行内的（已完成任务的结果文件仍在磁盘上）。

**Q：我把普通聊天打成了 /task 开头怎么办？**
没关系，说"取消"或 `/task cancel` 即可；或者直接看它给你的回执。

**Q：命令打错了？**
输 `/bridge` 随时看帮助。
